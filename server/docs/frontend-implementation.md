# 管理控制台 0.3.0 实现说明

本次交付把前端规划落实为 Vue 3 / TypeScript / Element Plus 管理控制台，构建后由同一个 Go 服务提供页面和 API。软件版本 0.3.0，OpenAPI 1.9.0；网关采集协议仍兼容 1.0 / GW32 1.1，未另造设备协议。数据目录、加密密钥和原有数据库迁移保持原有管理方式。

## 页面与布局

共 **7 大类、23 个业务页面 + 1 个登录页 = 24 页**。侧栏 **18 个入口**，5 个详情/配置页面从对应对象进入。公共框架为左侧分类导航、顶部账号及当前位置、主工作区；窄屏折叠导航，表格在自身容器内横向滚动。逐字段布局及原始需求见 [总体规划](frontend-plan.md)。

| 大类 | 页面编号 | 主要布局及真实操作 |
| --- | --- | --- |
| 登录 | P00 | 账号密码表单、错误提示、首次登录说明；Cookie 会话恢复 |
| 运行概览 | P01 | 当前状态卡、组件状态、规则节点、磁盘余量；无虚构历史曲线 |
| 网关设备 | P02–P04 | 分组树 + 网关表；详情页签 + 操作区；配置分区 + 显式修改字段 + 差异预览 |
| 蓝牙连接 | P05–P07 | 对端登记；连接列表 + GATT 任务表单及订阅；自动连接规则编辑及触发记录 |
| 数据处理 | P08–P12 | 事件筛选 + 修订/原文/输出；解析试算；不可变规则包编辑、验证、激活；隔离与重解析 |
| 客户转发 | P13–P15 | 目标列表；HTTP/MQTT 版本 + 字段映射及样本预览；投递详情、冻结载荷与原投递重试 |
| 任务与升级 | P16–P18 | 命令筛选；请求/结果历史及验证；制品上传、签名元数据与固件任务 |
| 系统管理 | P19–P23 | 范围树；人员/应用/凭据；状态及诊断作业；审计；本地中文接入指南及契约下载 |

所有业务操作调用服务器；没有静态样例冒充实时状态。示例只出现在解析器试算和协议指南，明确标识用途。签名制品上传要求真实签名，页面不提供绕过验签的导入方式。

## 增补的服务器接口

原有 65 个操作扩展为 **78 个操作、127 个 schema**。新增接口均为只读；写操作继续使用已有的授权、ETag、幂等和持久化路径。

| GET 路径 | 用途 / 约束 |
| --- | --- |
| `/api/v1/gateways/{gatewayId}/configuration/effective` | 合并已验证配置 patch，返回 knownPaths、来源任务与修订；complete=false |
| `/api/v1/tasks/{taskId}/request` | 持久命令请求及摘要，敏感字段脱敏 |
| `/api/v1/tasks/{taskId}/results` | 按 sequence 的回执历史及分页，标识正文是否保留 |
| `/api/v1/outputs/{outputId}` | 实际持久解析输出；同网关 data:read + data:raw |
| `/api/v1/deliveries/{deliveryId}/payload` | 冻结客户报文；delivery:read + data:raw |
| `/api/v1/gateways/{gatewayId}/events/{eventId}/deliveries` | 按事件关联投递身份 |
| `/api/v1/artifacts` | 实例范围制品列表，可按 kind 筛选 |
| `/api/v1/reprocess-jobs` | 当前发起者的重解析作业，可按 state 筛选 |
| `/api/v1/operations` | 所有者或实例维护者的维护作业，可按 kind/state 筛选 |
| `/api/v1/ble-peers/{peerId}` | 单个对端详情 |
| `/api/v1/auto-connect-rules/{ruleId}` | 单条规则详情 |
| `/api/v1/gatt-subscriptions` | 按 gatewayId / connectionRef 查询订阅 |
| `/api/v1/auto-connect-triggers` | 按 gatewayId / ruleId 查询自动触发证据 |

分页不伪造总数；页面明确显示当前批次或已加载数量。超过已有快照候选上限时返回错误并要求收窄查询。原文、输出或回执正文回收时显示不可用，不重新试算后冒充历史输出。

## 一致性、安全与状态处理

- 浏览器同源访问，HttpOnly 会话 Cookie 加 CSRF。`GET /auth/me` 的同源响应头提供 CSRF 恢复证明，新标签页无需读取会话令牌。会话过期时转回登录；过期后退出也清理本地状态。
- 菜单、按钮和表单按照固定角色与范围控制；最终授权仍由服务器执行。人员管理、制品、目标及规则包的实例权限与分组权限不混同。
- 配置表单只提交勾选的字段。累计已确认值不是设备当前全量回读，未知值不会被默认配置覆盖。变更先显示 patch，设备最终生效以 VERIFIED 任务结果为准。
- ETag 冲突保留草稿；网络不确定时保留原幂等键及固定 expiresAt。明确的一次成功结束后，新的 GATT 读取创建新任务；不把重复查询误当幂等重放。
- 解析器输入变化立即清除旧试算，乱序响应不得覆盖最新输入或最新选中对象。规则激活的人工重试固定 bundle、预期修订和幂等身份。
- UNKNOWN 任务不盲目重发，关闭连接不允许继续执行读写；设备能力缺失时不启用物理操作按钮。
- 应用令牌一次展示，只放组件内存；刷新/离开即清除。凭据签发没有自动重试，结果不确定时要求先核对凭据列表。密钥只保存服务器引用。
- HTML/JSON 按文本转义；静态脚本 CSP 仅允许同源，禁止内联脚本。入口不缓存，带内容 hash 的资源长期缓存。Go 使用 `all:` 嵌入辅助资源并逐个检查构建文件完整性。

前后端联调同时修正了原审计成功值与 OpenAPI 枚举的差异；资源范围和审计列表先关闭数据库查询游标再检查授权，避免并发时占满连接池。

## 本地部署

入口为 `server/scripts/deploy-local.ps1`；默认访问 `http://127.0.0.1:18780/ui/`，账号 admin，密码仅保存在 `server/.local/frontend-local/secrets/admin-password`。实例在后台运行，使用自己的 `data` 目录，不把 UI 测试数据放入交付实例。

Start / Status / Stop 检查 PID、可执行文件路径和启动时间，避免停止其他进程。重新启动保留数据与凭据。当前是本机回环部署，非开机自启 Windows 服务；客户生产服务器沿用 TLS 和现有 Linux 部署流程。构建和操作命令见 [前端 README](../../frontend/README.md)。

## 验证与后续边界

可重复的验证入口：前端类型检查与构建、API 幂等/CSRF 测试、网关字段校验、Go 全量测试与 vet、4 组 Chrome 浏览器联调脚本、原 1.1 进程级端到端脚本。测试 fixture 使用真实服务器以及两端软件模拟器，分别验证页面操作与持久记录。浏览器证据覆盖多角色访问、页面深链接、新标签恢复、窄屏、故障重试、配置/GATT、解析重解析/投递、账号凭据与诊断；具体执行结果见 [0.3.0 验证报告](frontend-validation.md)。

仍需在目标现场验证：实际网关固件和射频动作、真实 MQTT Broker/TLS、固件写入和回滚、断电及目标规模压力。历史监控曲线、任意解析脚本、跨主机数据库集群、主机在线升级和自动主备不属于这次前端实现。服务器停机备份/恢复仍通过维护工具完成，页面给出说明，不提供伪在线备份按钮。
