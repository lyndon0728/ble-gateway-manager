# ESP32-S3 固件变更记录

## 0.2.1 — 2026-11-19

本次按现有182条需求补齐运行边界，不新增服务器任务类型或UART命令。构建与测试证据见[验证记录](VALIDATION.md)，实板验收仍按[50项计划](../../docs/esp32s3-validation-plan.md)执行。

| 需求 | 源码更新 | 目的 |
| --- | --- | --- |
| ESP-EOTA-012/013/015/020 | 在升级记录持久化后、首次擦写前及分块处理边界重新检查原授权期限 | 存储或Flash耗时不能使过期请求继续执行，也不能重置授权预算 |
| ESP-EOTA-003/020 | 远程签名清单明确给出大小/格式时严格校验，下载限额及最终长度绑定签名值 | 在擦写之前拒绝不合适的发行物，同时保留旧制品省略字段的兼容性 |
| ESP-EOTA-015/016/017/018 | 本地启动槽选择结果不确定时保留安装意图和维护责任，经重启按实际槽与镜像恢复 | 不把底层写入报错当作“安装一定没有发生”，防止后续任务覆盖恢复依据 |
| ESP-PROV-003/004、ESP-SEC-003 | 配网HTTP正文使用固定接收期限，关窗主动中断已接受连接 | 慢速请求不能无限延长热点窗口，已关闭窗口不继续分派业务 |
| ESP-SYS-006、ESP-CFG-004/006 | 已报告配置版本只随已验证成功结果单调推进 | 迟到的旧结果/重复ACK不把新配置版本退回旧值 |

0.2.1不改变制造密钥、Flash布局、既有配置/事件记录格式，也不自动烧录设备或设置eFuse。默认现场入口及板卡引脚约束继续见[README](README.md)。

## 0.2.0 — 2026-11-19

增加ESP本地网页OTA、签名发行打包工具、独立本地恢复记录、实际运行版本心跳及完整本地入口构建检查；与现有服务器远程OTA共用设备信任根和应用分区。
