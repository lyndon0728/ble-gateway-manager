## 8. 证据目录建议

```text
<受控证据根目录>/<批次ID>/
  report.md
  baseline/                 # 版本、配置摘要、接线/能力和阈值
  cases/<MAN编号>/<轮次ID>/ # 脱敏操作记录、查询、抓包和波形
  defects/<缺陷ID>/         # 复现、修复提交及复测证据
  soak/                    # 72小时采样与最终核账
  evidence-index.md         # 每个证据的文件名、SHA-256、时间、采集人与权限
```

记录模板和脱敏Markdown可进入项目仓库；原始秘密材料、设备NVS、私钥、平台数据备份不随测试报告上传GitHub。
