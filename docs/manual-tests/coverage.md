# 人工测试覆盖与验收编号对照表

文档版本：1.0；日期：2026-11-19。返回[人工测试总册](../gateway-manual-test-plan.md)。本表为执行索引，不是测试结果；全部人工执行状态初始为“未执行”。

## 1. 如何使用

本包共87个稳定编号：5个上板准备、29个UART/无线/Beacon、32个网络/OTA、20个平台/贯通用例，以及1个范围待确认的C05附录。86个为必测计划入口；实际按radio、传输、浏览器、故障点和能力展开为多条记录，不以87代替执行条数。

以下逐项保留95个原验收编号：ACC 18项、ESP 50项、BFLT 16项、平台11项。ACC-11和ESP-AT-25为独立手机BLE业务，范围待确认；其余93项进入当前验收计划，但缺目标镜像、板级批准、实现或工装时应记“阻塞”，不能因此标通过。

执行时同时打开原编号的详细要求与对应MAN步骤。MAN是人工操作入口，多个入口可能只覆盖同一原编号的不同部分；原编号整体通过须其全部适用子场景及专项证据齐全。原计划要求的Flash水位破坏、严格字段负例、MCUboot交换边界、RF测量等，不因MAN写成概览而被取消。没有工程师提供的可复现注入方法/观察字段时记阻塞；不得编造生产API或用正常重启代替故障注入。

每个MAN引用必须填[记录模板](record-template.md)中的实际状态；同时在原编号汇总中关联其子项记录。覆盖表中的对应关系不表示已经通过，也不表示增加了未授权功能。ESP-AT-21的标准BLE连接/广播生命周期保留，C05业务认证仍不纳入必测。

## 6. 交接校验与报告门槛

- 文档包校验只核对编号、链接、示例格式及覆盖关系；不执行设备/平台测试，不预填任何实测数据。
- 已知缺口必须跟随报告：nRF目标构建和实板证据、本板射频/复位放行、重复配网入口、存储迁移入口、精确故障工装及长稳容量限制。
- 本批报告分别列出通过、失败、阻塞、未执行、范围待确认和不适用；“不适用”需范围依据，不能用于隐藏原定必测缺口。
- 测试负责人逐项签收证据、缺陷和恢复结果后才能填写结论；无实测记录时整包状态保持“待人工执行”。
